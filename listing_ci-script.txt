BUILD PROCESS:
--------------
1. Clean build directory (rm -rf build)
2. Create build directory (mkdir build)
3. Change to build directory (cd build)
4. Configure with CMake:
   cmake .. -G "MinGW Makefiles"
5. Build:
   cmake --build .
   - Builds main executable (main.exe)
   - Builds math_operations library (libmath_operations.a)
   - Builds GoogleTest components (gtest, gtest_main)
   - Builds unit_tests executable (unit_tests.exe)
6. Run tests:
   ctest --output-on-failure
   - Executes all registered tests
   - Shows output if test fails
